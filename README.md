# Machine Learning Journey 🚀

A collection of my self-learning projects, experiments, and notes as I explore Machine Learning — from fundamentals to more advanced techniques. This repo serves as both a personal learning log and a portfolio of hands-on work.

## 📌 About

This repository documents my journey into Machine Learning. Each folder/project represents a concept, algorithm, or technique I've studied and implemented from scratch or using popular libraries. The goal is to build intuition through practice, not just theory.

## 📂 Repository Structure

```
├── 01-fundamentals/          # Python, NumPy, Pandas, data preprocessing basics
├── 02-supervised-learning/   # Regression, classification (Linear/Logistic Regression, SVM, Trees, etc.)
├── 03-unsupervised-learning/ # Clustering, dimensionality reduction (K-Means, PCA, etc.)
├── 04-neural-networks/       # Basics of NNs, backpropagation from scratch
├── 05-deep-learning/         # CNNs, RNNs, Transformers (using PyTorch/TensorFlow)
├── 06-nlp/                   # Natural Language Processing experiments
├── 07-projects/              # End-to-end mini projects
├── datasets/                 # Sample datasets used across projects
└── notes/                    # Markdown notes, cheat sheets, and summaries
```

- Build a strong foundation in ML theory and math (linear algebra, probability, statistics)
- Implement algorithms from scratch before using libraries

## 🚀 Getting Started

Clone the repository:

```bash
git clone git@github.com:MarjanEs/ML.git
cd ML.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Open notebooks with Jupyter:

```bash
jupyter notebook
```
